# v8.5.5 server update

This incremental package is installed over v8.5.4.

The top-right header links are replaced by one account button. It shows a
profile icon and the user's first/last name when configured in **My Profile**;
otherwise it shows the username. Open it to access My Profile, Manage Users
(Administrators only), and Sign out.

Copy the package contents to `/opt/gns3-lab-portal`, restart the portal
service, and hard-refresh the browser.
