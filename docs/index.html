Build labs safely.

The portal gives support teams a controlled way to create, manage, back up, share, and reuse GNS3 labs—without exposing the controller API to every user.

Stay tuned for v9.0. The next major release prepares MariaDB-backed identity, granular roles, LDAPS/Active Directory group mapping, and an optional separately secured database-administration console.

Current portal flow — v8.5.9

v9.0 roadmap

Identity and access

MariaDB becomes the portal system of record. Local accounts remain available, using Argon2id password hashes and server-side sessions.

LDAPS and AD groups

Administrators will configure LDAPS with corporate certificate validation, import AD groups, and map them to portal roles.

Granular roles

Planned roles include Platform Admin, Lab Manager, Template Approver, Lab Editor, Lab Operator, Viewer, and Auditor.
