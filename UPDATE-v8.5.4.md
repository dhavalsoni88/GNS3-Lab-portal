# v8.5.4 server update

This incremental package is installed over v8.5.3.

- The **Completed at** column replaces the longer timestamp heading.
- Select one backup to make a template. Its backup name is suggested but can be
  changed before publishing.
- Select one or more backups, then use **Delete selected**. The browser asks
  for confirmation before any backup is permanently removed.
- Download, Restore, and Share remain on each individual backup row.

Copy the package contents to `/opt/gns3-lab-portal`, restart the portal
service, and hard-refresh the browser.
