# noVNC (vendored)

The `core/` and `vendor/pako/` folders of [noVNC](https://github.com/novnc/noVNC) v1.5.0
(commit 7fcf9dcfe0cc5b14e3841a4429dc091a6ffca861), unchanged, licensed MPL-2.0 (see LICENSE.txt;
pako is MIT). The appliance builder's job page uses it to show a build VM's screen in the browser.
Served locally so the portal works on networks without internet access.
